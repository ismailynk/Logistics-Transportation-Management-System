# 🚚 Logistics & Transportation Management System

A Windows desktop application developed using Visual Studio as a university Database Systems course project. The application provides a centralized management solution for logistics companies, covering employee records, salaries, job titles, vehicles, products, customers, routes, and transportation operations.

### ✨ Key Features

- 👥 **Personnel Management:** Register employees and manage their information.
- 💰 **Salary & Position Management:** Assign salaries and job titles to personnel.
- 🚛 **Vehicle Management:** Register and manage transportation vehicles.
- 📦 **Product Management:** Create and maintain product records.
- 👤 **Customer Management:** Store and manage customer information.
- 🗺️ **Route Management:** Define transportation routes.
- 🚚 **Trip Management:** Create trips by selecting a vehicle, driver, product, customer, and route.
- 🔗 **Relational Database Architecture:** Multiple interconnected tables linked through primary keys and foreign key constraints.
- 🛡️ **Data Integrity:** Maintain consistent relationships between all business records.

### 🗄️ Database Design

The application uses a relational database structure with interconnected tables for personnel, salaries, job titles, vehicles, products, customers, routes, and transportation trips.

Foreign key relationships ensure data consistency and establish connections between different entities.

### 🛠️ Technologies Used

- Microsoft Visual Studio
- Windows Forms Desktop Application
- Relational Database Management System
- SQL
- Primary Keys & Foreign Keys

### 🎯 Project Goal

Developed to demonstrate practical database design and management concepts through a Windows-based logistics application. The project focuses on relational database architecture, entity relationships, data integrity, and the management of real-world transportation operations.
